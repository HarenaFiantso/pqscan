Usage: pqscan [OPTIONS] PATH...

Find quantum-vulnerable cryptography in C/C++ source, TLS and SSH configuration,
certificates, keys and ELF binaries.

Options:
  -i, --ignore PATTERN  skip paths matching this glob (repeatable; .git is always skipped)
  -r, --rules FILE      use the rules in this JSON file instead of the built-in ones
  -f, --format FORMAT   write the report as text, json, cbom or sarif
      --fail-on LEVEL   lowest risk level that exits 1: OK, REVIEW, QUANTUM_VULNERABLE or
                        CLASSICALLY_WEAK (default REVIEW)
      --max-time SECS   start on no new file after this long (default 3600)
  -h, --help            show this help and exit
  -V, --version         show the version and exit

Exit codes:
  0  no findings at or above --fail-on, and everything was analyzed
  1  findings at or above --fail-on
  2  usage error
  3  internal error
  4  no findings at or above --fail-on, but something could not be analyzed
